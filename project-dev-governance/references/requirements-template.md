# 需求清单模板

## 文档级字段

- 项目名称
- 版本号
- 编制日期
- 编制人
- 审核人
- 确认人
- 依据文件

## 总体范围

- 本期建设目标
- 本期范围内
- 本期范围外
- 关键约束

## 总台账字段

| 字段 | 说明 |
| --- | --- |
| 需求编号 | 全局唯一 |
| 模块 | 经管 / 安全 / APP / 其他 |
| 功能组 | 业务域分组 |
| 功能点名称 | 最小可交付功能点 |
| 优先级 | P0 / P1 / P2 |
| 来源 | 报价、会议、原型、文档 |
| 是否本期 | 是 / 否 |
| 所属迭代建议 | Sprint 编号 |
| 责任人 | 业务/开发 |
| 备注 | 风险、依赖、争议 |

## 功能点字段

- 业务场景
- 现状痛点
- 目标效果
- 功能说明
- 输入项
- 输出项
- 数据来源
- 计算口径
- 权限规则
- 状态流转规则
- 异常处理规则
- 涉及接口
- 涉及表/字段
- 跨模块联动
- 验收标准
- 测试要点
- 待确认问题
